# Sami Bouyat — Portfolio

Site portfolio one-page présentant le profil de **Sami Bouyat**, Tech Lead Java & Angular.

## Stack

HTML / CSS / JavaScript vanilla — aucune étape de build requise.

```
.
├── index.html
├── css/style.css
├── js/script.js
└── README.md
```

## Lancer en local

Ouvrir simplement `index.html` dans un navigateur, ou servir le dossier :

```bash
python3 -m http.server 8080
# puis ouvrir http://localhost:8080
```

## Déploiement (GitHub Pages)

1. Sur GitHub : **Settings → Pages**
2. Source : **Deploy from a branch**
3. Branch : `main` / dossier `/ (root)`
4. Le site sera disponible sur `https://samibouyat-wq.github.io/portfolio/`

## Personnalisation

- Contenu : éditer directement `index.html` (expériences, compétences, coordonnées).
- Couleurs / thème : variables CSS en haut de `css/style.css` (`:root`).
